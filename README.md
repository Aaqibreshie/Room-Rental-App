# 🏠Room Rental Application--Roomify

Roomify is a full-stack MERN application that helps students and individuals find rental rooms easily. Property owners can list available rooms, and users can browse, search, and contact owners seamlessly.

---

## 🚀 Features

### 👤 User Features
- User registration & login (JWT authentication)
- Browse available rooms
- Search and filter rooms by location and price
- View detailed room information
- Contact room owners

### 🏠 Owner Features
- Owner registration & login
- Add new rooms for rent
- Update room details
- Delete listed rooms
- View their listed properties

### 🔐 Security
- JWT-based authentication
- Protected routes
- Password hashing using bcrypt
